# Databricks Genie

- For questions about business data in Databricks (metrics, revenue, customers, which table holds what), ask Genie with `genie_ask` and `genie_poll_response` instead of guessing table names or writing SQL from memory. The `genie` skill has the details.
- When you use a Genie answer, show its SQL and include the "Explore in Databricks" link it returns.
- Never print, log, or write Databricks tokens.
